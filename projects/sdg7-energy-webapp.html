Data-Driven Web App: Communicating UN SDG 7

Type
Exam project — Data Driven Applications
Tools
HTML · CSS · JavaScript · Leaflet · REST APIs
Goal
Communicate clean energy access data

Problem / Goal

Make complex global energy data accessible and engaging to a general audience, focused on UN Sustainable Development Goal 7 (Affordable and Clean Energy) — specifically renewable energy share, energy efficiency, and international support for clean energy.

What I did

Data & design
  • Merged two public Kaggle datasets (global energy mix, electricity access/GDP) into one structured CSV
  • Structured the site as a single-page storytelling flow: intro, interactive exploration, then synthesis
Interactive visualizations
  • World map (Leaflet) colored by electricity access %, with a year selector
  • Linked line chart and summary table showing renewable vs. non-renewable trends per selected country
External API integrations
  • New York Times API — live news on renewable/clean energy, parsed and rendered dynamically
  • YouTube Data API — related educational videos, parsed for title/thumbnail/link
  • Handled both with async/await, proper error handling, and dynamic DOM insertion

Code sample

The map's year filter, pulled directly from the project — parses the dataset once, then redraws country markers whenever the year changes rather than reloading the map.

script.js — map year filter 
function updateMapForYear(year) {
  if (!accessLayer || !energyData.length) return;

  accessLayer.clearLayers();

  const rows = energyData.filter(
    row => Number(row[COL_YEAR]) === Number(year)
  );

  rows.forEach(row => {
    const lat = toNum(row[COL_LAT]);
    const lon = toNum(row[COL_LON]);
    const access = toNum(row[COL_ACCESS]);

    if (Number.isNaN(lat) || Number.isNaN(lon) || Number.isNaN(access)) {
      return;
    }

    const color = getAccessColor(access);

    const circle = L.circleMarker([lat, lon], {
      radius: 6,
      color,
      fillColor: color,
      fillOpacity: 0.85,
      weight: 0.7
    });

    circle.bindPopup(`<strong>${row[COL_ENTITY]}</strong><br/>
      Access to electricity: ${access.toFixed(1)}%<br/>
      Year: ${year}`);

    circle.addTo(accessLayer);
  });
}

function getAccessColor(access) {
  if (access < 40) return "#d73027";
  if (access < 70) return "#fc8d59";
  if (access < 90) return "#fee08b";
  if (access < 99) return "#91cf60";
  return "#1a9850";
}

Key findings

  • Kept visualizations to 3 core types (map, chart, table) rather than overloading with more, to avoid cognitive overload
  • Capped external content (7 articles, 4 videos) to match layout and avoid overwhelming the user
  • The underlying data reinforced that closing the SDG 7 gap depends on more than technology — economic conditions, infrastructure, and policy all matter
