Customer Churn Prediction

Type
ML exam project, group work
Tools
Python · scikit-learn · TensorFlow/Keras · SHAP
Dataset
Telco Customer Churn (Kaggle)
Method
Classical ML, neural nets, autoencoders

Problem / Goal

Predict which customers are likely to churn, comparing multiple modeling approaches — classical ML, neural networks, and representation learning via autoencoders — to see which best identifies at-risk customers.

What I did

EDA & preprocessing
  • Explored the dataset, checked for outliers, correlations, and class imbalance
  • Cleaned data, engineered features, converted binary fields; fit preprocessing on train only to avoid leakage
Shallow learning models
  • Logistic regression, random forest, gradient boosting, and XGBoost, with cross-validation focused on F1
  • Built a stacked ensemble combining multiple models
Neural network models
  • Feedforward neural network with class weighting to address churn imbalance
  • Tuned the classification threshold, evaluating the tradeoff between accuracy and recall on churners
  • Evaluated using loss, accuracy, AUC, and ROC curves
Autoencoders & explainability
  • Trained autoencoders to compress features into latent embeddings at multiple dimensions
  • Compared logistic regression and FFNN performance on raw features vs. latent embeddings
  • Applied SHAP to explain predictions — global feature importance and individual waterfall plots

Key findings

  • Class imbalance required deliberate handling (class weights, F1-focused evaluation, threshold tuning) rather than relying on accuracy alone
  • Threshold tuning showed a clear tradeoff: small accuracy losses could meaningfully increase churner detection
  • Autoencoder-based latent embeddings were compared directly against raw features to test whether compression improved or hurt predictive performance
  • SHAP made it possible to explain not just which model performed best, but why — which features drove individual predictions

Skills demonstrated

EDA & data cleaning Class imbalance handling Classical ML & stacking Neural network design (Keras) Threshold tuning Autoencoders SHAP interpretability Leakage-safe methodology
