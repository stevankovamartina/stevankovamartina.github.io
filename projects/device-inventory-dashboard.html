Device Inventory & Utilization Reporting Dashboard

Type
Professional project (confidential)
Tools
Power BI · Azure
Context
Siemens Energy, Vejle, Denmark

Problem / Goal

The organization needed visibility into hardware assets (tablets and accessories) deployed and stored across multiple international offshore energy projects and countries. Devices were tracked inconsistently across teams, making it hard to see utilization rates, identify surplus stock, or plan reallocation. I built a centralized reporting dashboard to solve this.

What I did

  • Consolidated device inventory data (serial numbers, device models, project assignments, country locations, and usage status) into a single Power BI data model
  • Designed a multi-panel dashboard: a hierarchical breakdown of stock by project/location, an in-use vs. in-stock KPI view, a searchable filterable device table, a geographic distribution map, and a device-model breakdown
  • Built interactive filtering so non-technical stakeholders could self-serve answers without requesting custom reports
  • Deployed and maintained the report on Microsoft Azure for organization-wide access

Key findings

  • Gave leadership a single source of truth for device location and status across all active projects, replacing manual spreadsheet reconciliation
  • Surfaced underused stock sitting idle in specific locations, informing reallocation decisions instead of new purchases
  • Reduced the time project managers spent manually compiling device status updates for internal reporting
  • Made reporting self-service, cutting down ad hoc requests to the data/ops team
