Subjective & Objective Sleep Patterns Across Sleep Disorders

Type
MSc Thesis, Data Science
Tools
Python · scikit-learn · SHAP · TensorFlow/Keras
Dataset
28,534 patients — PSG + questionnaire data
Method
PCA, clustering, classification, autoencoders

Problem / Goal

Insomnia, Obstructive Sleep Apnea (OSA), and their comorbidity (COMISA) have overlapping symptoms that make diagnosis difficult. This thesis investigated whether these clinically defined sleep disorders can be separated using machine learning, and how much subjective (questionnaire) vs. objective (polysomnography) data contributes to that separation.

What I did

  • Data integration & cleaning — merged questionnaire metadata (540K+ records) with PSG-derived hypnodensity files via patient ID, validated timestamps, and handled missing data without global imputation to preserve diagnostic integrity; final analysis set of 28,534 patients across 4 clinical groups (Control, Insomnia, OSA, COMISA)
  • Derived variable construction — built clinical outcome labels from raw questionnaire items and PSG indices using literature-based thresholds
  • Feature engineering — extracted entropy and stage-probability summary features from raw hypnodensity time series to make them usable for classical ML
  • EDA & unsupervised analysis — PCA (with/without diagnostic variables) and clustering (k-means, hierarchical, DBSCAN) to explore natural structure and overlap between groups
  • Supervised classification — trained and tuned 4 shallow models (Logistic Regression, Random Forest, Gradient Boosting, SVM) across multiclass and binary settings, with leakage-prevention filtering and stratified train/test splits
  • Model interpretability — SHAP analysis across all models and settings to identify which features drove each disorder's classification
  • Feature-group contribution analysis — compared performance using questionnaire-only, PSG-only, and combined feature sets
  • Nonlinear representation learning — built an autoencoder (172→10 dims) to compare against PCA and re-ran classification on the learned latent space

Key findings

  • All models substantially beat baseline; binary classification consistently outperformed multiclass, showing models struggle more when separating overlapping disorders simultaneously
  • OSA was most reliably classified, driven by objective PSG features (respiratory/arousal indices)
  • Insomnia was hardest to separate from Control, and relied mainly on subjective questionnaire data — objective PSG features added little
  • COMISA showed major overlap with OSA in multiclass settings but was strongly separable from Control in binary settings — the challenge is disentangling it from neighboring disorders, not detecting it
  • PCA and autoencoder latent spaces showed consistent, continuous overlap between groups — reinforcing that the overlap is a property of the clinical reality, not a modeling limitation
